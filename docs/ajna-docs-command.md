# Ajna docs command

The `symbolwright ajna docs` command prints the local Ajna documentation reference for operators.

It points to:

```text
docs/ajna/SYMBOLWRIGHT_AJNA_DOCS_HUB.md
docs/ajna-fixture-command-index.md
docs/ajna/SYMBOLWRIGHT_AJNA_ROADMAP.md
docs/ajna/SYMBOLWRIGHT_AJNA_BUILD_PLAN.md
```

## Boundary

This command renders documentation paths only.

It does not perform live GitHub ingestion, provider calls, PR comments, shell command execution, or repository mutation.
